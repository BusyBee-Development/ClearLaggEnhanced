# Sidebar structure reference

Intended category order and labels, matching the live site's current sidebar plus the two module
pages it was missing. Use this to build `sidebars.js` or per-folder `_category_.json` files.

```
ClearLaggEnhanced
├── Introduction .......................... intro.md
├── Getting Started
│   ├── Quick Start ........................ getting-started/quick-start.md
│   ├── Installation ....................... getting-started/installation.md
│   └── Requirements ....................... getting-started/requirements.md
├── Core Reference
│   ├── Commands & Permissions ............. core-reference/commands-permissions.md
│   └── Admin GUI ........................... core-reference/admin-gui.md
├── Features & Modules
│   ├── Entity Clearing ..................... features-modules/entity-clearing.md
│   ├── Mob Limiter .......................... features-modules/mob-limiter.md
│   ├── Spawner Limiter ...................... features-modules/spawner-limiter.md
│   ├── Misc Entity Limiter .................. features-modules/misc-entity-limiter.md
│   ├── Chunk Finder .......................... features-modules/chunk-finder.md
│   ├── Performance Monitor .................. features-modules/performance-monitor.md
│   ├── Packet Limiter (NEW) ................. features-modules/packet-limiter.md
│   └── AFK Optimization (NEW) ............... features-modules/afk-optimization.md
├── Configuration
│   ├── Main Configuration ................... configuration/main-configuration.md
│   ├── Module Configuration ................. configuration/module-configuration.md
│   ├── Message Customization ................ configuration/message-customization.md
│   └── Database Setup ....................... configuration/database-setup.md
├── Integrations
│   ├── PlaceholderAPI ........................ integrations/placeholderapi.md
│   ├── Stacker Plugins ....................... integrations/stacker-plugins.md
│   ├── ModernShowcase ......................... integrations/modernshowcase.md
│   └── GriefPrevention3D (NEW) ................ integrations/griefprevention3d.md
├── Advanced Optimization
│   ├── Performance Guide ..................... advanced-optimization/performance-guide.md
│   ├── Folia Support .......................... advanced-optimization/folia-support.md
│   ├── Migration Guide ........................ advanced-optimization/migration-guide.md
│   └── Troubleshooting ........................ advanced-optimization/troubleshooting.md
├── Support
│   ├── FAQ ..................................... support/faq.md
│   ├── Common Issues ........................... support/common-issues.md
│   └── Getting Help ............................ support/getting-help.md
└── Materials .................................... materials.md
```

`(NEW)` marks pages that didn't exist on the previous live site.
