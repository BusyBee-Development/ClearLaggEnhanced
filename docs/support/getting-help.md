# Getting Help

- **Bug reports & feature requests:** [GitHub Issues](https://github.com/BusyBee-Development/ClearLaggEnhanced/issues) —
  please include your server type/version, the plugin version, and the relevant config section
  when reporting a bug.
- **Community support & discussion:** [Discord](https://discord.gg/abdm29q7af)
- **Source code:** [github.com/BusyBee-Development/ClearLaggEnhanced](https://github.com/BusyBee-Development/ClearLaggEnhanced)
- **Downloads:** [Modrinth](https://modrinth.com/plugin/clearlaggenhanced)

Before asking for help, check [FAQ](faq.md), [Common Issues](common-issues.md), and
[Troubleshooting](../advanced-optimization/troubleshooting.md) — most day-to-day questions are
already answered there.
